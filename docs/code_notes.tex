\section{Training Core}
\textbf{File:} \path{p1_training/training_core.py}.\\
\textbf{Role:} shared training loop for the baseline and experiments.\\
\textbf{Why it matters:} all software comparisons pass through the same training
path, so the current 95.70\% accuracy and 56.48\% sparsity numbers are comparable
across baseline and experiment runs.\\
\textbf{Key interfaces:} \texttt{load\_config()} and
\texttt{train\_from\_config()}.

\section{SNN Model}
\textbf{File:} \path{p1_training/model.py}.\\
\textbf{Role:} defines the proposal-aligned SNN model.\\
\textbf{Model used:} MNIST input flattened to 784, hidden layers of 128 and 64
LIF neurons, and 10 output classes.\\
\textbf{Notes:} the model supports temporal spike encoding and fake quantization
for hardware-oriented experiments.

\section{Hardware Proxy Estimators}
\textbf{File:} \path{p2_hardware_model/estimators.py}.\\
\textbf{Role:} provides lightweight hardware proxy estimates.\\
\textbf{Current use:} the latest run uses these estimators to compare baseline
energy proxy (22,604,295.76) with the best hardware-aware run
(4,592,863.17).\\
\textbf{Key interfaces:}
\begin{itemize}
\item \texttt{estimate\_spike\_cost()}
\item \texttt{estimate\_memory\_access()}
\item \texttt{estimate\_energy\_proxy()}
\item \texttt{estimate\_latency\_proxy()}
\end{itemize}
