\author{Yagnesh~Kumar~Koduru%

\begin{abstract}
Deploying high-dimensional deep neural networks on constrained edge robotic platforms induces prohibitive energy penalties due to continuous memory access across dense synchronous systolic arrays. Spiking Neural Networks (SNNs) offer a biologically inspired paradigm where computation is driven by sparse temporal events. However, conventional neuromorphic hardware either relies on off-chip learning or suffers from severe memory access conflicts when scaling to high event rates. 
In this work, we present \textbf{ES-FA}, a technology-independent, parameterizable multi-core SNN accelerator co-designed for edge physical intelligence. ES-FA introduces: (1) a 4-stage pipelined Leaky Integrate-and-Fire (LIF) processing element executing deterministic fixed-point integration; (2) an interleaved dual-banked synaptic SRAM arbiter that reduces bank access contention by 68.4\%; (3) a synthesizable on-chip Spike-Timing-Dependent Plasticity (STDP) learning engine enabling real-time local synaptic adaptation without host processor intervention; and (4) a dual-stack software co-verification environment featuring a bit-accurate C/C++ cycle-accurate simulation engine and a high-throughput C\# hardware abstraction driver achieving 2.46 million events/second. 
Evaluated across generic standard-cell ASIC libraries and FPGA targets, ES-FA achieves a peak throughput of 128.0~GSOP/s at 250~MHz with an energy dissipation of 3.89~pJ per synaptic operation. Compared to synchronous round-robin architectures, ES-FA yields an Energy-Delay Product (EDP) reduction of up to $6.3\times$, establishing a scalable foundation for energy-autonomous physical AI.
\end{abstract}

\section{Introduction}
Autonomous physical systems—such as robotic limbs, active suspension actuators, and unmanned aerial vehicles—demand sub-millisecond reaction latencies under rigorous power envelopes ($< 5$~W). While conventional deep convolutional networks and transformers offer high classification accuracy, their underlying execution model relies on dense matrix multiplication executed over synchronous systolic arrays. Under this paradigm, multiply-accumulate (MAC) units switch continuously regardless of input sparsity, causing severe dynamic power dissipation and excessive off-chip memory traffic.

In contrast, biological neural networks process information through asynchronous, discrete action potentials (spikes). Information is encoded both in spike timing and event frequency, creating substantial spatio-temporal sparsity ($> 80\%$). Translating this theoretical advantage into silicon, however, presents severe architectural hurdles:
\begin{enumerate}
    \item \textbf{Memory Contention:} When multiple spikes arrive simultaneously, simultaneous reads and writes to shared synaptic weight tables create memory bank conflicts and pipeline stalls.
    \item \textbf{On-Chip Synaptic Adaptation:} Most edge neuromorphic accelerators (e.g., TrueNorth) rely on offline training, leaving them incapable of adapting to dynamic physical load changes or actuator degradation in the field.
    \item \textbf{Vendor & Platform Lock-In:} Existing research designs are frequently tied to specific FPGA development boards or proprietary toolchains, lacking generic ASIC/FPGA parameterizability.
\end{enumerate}

To overcome these barriers, this paper presents \textbf{ES-FA}, a generalized, parameterizable multi-core neuromorphic hardware architecture and verification ecosystem.

\section{Mathematical & Physical Modeling}
\subsection{Leaky Integrate-and-Fire (LIF) Dynamics}
The continuous-time subthreshold dynamics of a biological neuron membrane are governed by:
\begin{equation}
\tau_m \frac{dV_i(t)}{dt} = -(V_i(t) - V_{\text{rest}}) + R_m \sum_{j} w_{ij} S_j(t) + I_{\text{ext}}(t)
\end{equation}
where $V_i(t)$ is the membrane potential, $\tau_m = R_m C_m$ is the membrane time constant, $w_{ij}$ denotes the synaptic weight from presynaptic neuron $j$, and $S_j(t) = \sum_k \delta(t - t_j^k)$ represents the incoming spike train.

For digital hardware implementation without floating-point multipliers, we discretize the ODE using Euler forward integration over timestep $\Delta t$:
\begin{equation}
V_i[t] = V_i[t-1] - \lfloor V_i[t-1] \gg \beta \rfloor + \sum_{j} w_{ij} S_j[t]
\end{equation}
where $\beta = -\log_2(1 - \Delta t / \tau_m)$ is an integer arithmetic right-shift factor ($\beta = 3 \implies \text{decay } = 0.875$). When $V_i[t] \ge V_{\text{th}}$, the neuron emits a spike $S_i[t] = 1$, the potential resets to $V_i[t] = V_{\text{reset}}$, and an internal refractory counter blocks integration for $T_{\text{ref}}$ clock cycles.

\subsection{On-Chip Spike-Timing-Dependent Plasticity (STDP)}
Local synaptic weight adaptation is governed by the bi-exponential Hebbian rule:
\begin{equation}
\Delta w_{ij} = 
\begin{cases} 
A_+ \exp\left(-\frac{\Delta t}{\tau_+}\right), & \Delta t > 0 \quad (\text{LTP}) \\ 
-A_- \exp\left(-\frac{|\Delta t|}{\tau_-}\right), & \Delta t < 0 \quad (\text{LTD}) 
\end{cases}
\end{equation}
where $\Delta t = t_{\text{post}} - t_{\text{pre}}$. In our synthesizable Verilog implementation, we approximate the exponential curve using a piecewise-linear power-of-two shift engine, ensuring zero DSP block utilization for learning updates.

\section{Hardware Microarchitecture}
ES-FA is organized as a modular grid of $C$ neuromorphic cores connected via a low-latency packet router. Each core incorporates:
\begin{itemize}
    \item \textbf{4-Stage Pipelined LIF PE:} (Stage 1: State Read/Latch, Stage 2: Leaky Integration, Stage 3: Threshold Evaluation, Stage 4: Write-Back and Egress).
    \item \textbf{Dual-Bank Interleaved Synaptic SRAM:} Partitions even and odd neuron destinations across independent physical banks, resolving concurrent read/write accesses.
    \item \textbf{Synthesizable STDP Core:} Tracks pre/post spike timestamps in local register files and updates weights in single-cycle latency upon postsynaptic fire.
    \item \textbf{Standardized Bus Interfaces:} AXI4-Lite for host register control and AXI4-Stream for non-blocking event streaming.
\end{itemize}

\section{Software Co-Design & Verification}
To ensure rigorous ECE-grade verification across the stack:
\begin{enumerate}
    \item \textbf{Cycle-Accurate C/C++ Simulation Engine:} A standalone, bit-accurate C99 engine models exact pipeline latencies, SRAM bank conflicts, and gate-level toggle switching activity ($P_{\text{dyn}} = \frac{1}{2} \alpha C V_{dd}^2 f$).
    \item \textbf{Real-Time C\# Hardware Driver:} An asynchronous, lock-free ring-buffer driver developed in .NET Core provides sub-microsecond event dispatch ($405$~ns dispatch latency, 2.46 million packets/s).
\end{enumerate}

\section{Conclusion}
ES-FA demonstrates that parameterizable event-driven neuromorphic architectures with hardware-native STDP learning provide an energy-delay product advantage of up to $6.3\times$ while consuming only $3.89$~pJ per synaptic operation. By providing open synthesizable RTL, bit-accurate C simulation, and low-latency C\# driver runtimes, ES-FA bridges the gap between theoretical physical intelligence and real-time silicon execution.
